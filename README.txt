TATIANA MAE DESIGNS PORTFOLIO

Open index.html in a browser to preview the site.

Main files:
- index.html
- about.html
- portfolio.html
- resume.html
- contact.html
- assets/css/style.css
- assets/js/site.js
- assets/images/
- assets/files/

To edit text, open the matching HTML file in VS Code.
To change colors, edit the color variables at the top of assets/css/style.css.

Free hosting recommendation:
1. Create a free GitHub account.
2. Create a new public repository named tatiana-portfolio.
3. Upload everything inside this folder.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.

GitHub will provide the public website address after publishing.
